# First AMOS lesson pair: review draft

These two drafts turn the first rows of the [agreed teaching map](../teaching-map.md)
into a beginner-facing explanation. They are not published replacement lessons.
Their scope is a five-line message, one edit and repair, then native Save and
an independent reopen. No game state, drawing routine or new mechanic enters.

1. [Put your first message on screen](01-first-message.md): type, check, run,
   wait, finish, return to editing, replace one line, predict and repair.
2. [Keep your words](02-keep-your-words.md): choose a writable disk and filename,
   distinguish a native program from a session, reopen and check the edit.

The complete listings come from the maintained
[opening sources](https://github.com/code198x/code-samples/tree/633cd580/commodore-amiga/amos/bank-or-risk/stages/opening).
The [opening audit](../../../../../audit/2026-10-amos-bank-or-risk-opening/REPORT.md)
records earlier Merge ASCII checks. The
[first-pair audit](../../../../../audit/2026-10-amos-first-lesson-pair/REPORT.md)
records the separate typed/edit/repair and native save/reopen route.
The [storage follow-up](../../../../../audit/2026-10-amos-storage-follow-up/REPORT.md)
qualifies the larger endpoint on the fixed emulator, without changing the
pre-fix failure record.

## Review and release boundaries

The page titles describe outcomes; the numbers order this bounded pair and do
not fix the eventual course length. Predictions precede explanatory reveals.
An experienced reader can enter the save lesson with the complete listing;
no Foundations attendance or quiz score is required.

The lesson pair starts at a blank AMOS Professional 2.00 editor. A complete
public beginner route must also qualify installation/startup, lawful runtime
availability, host keyboard mapping and modified-disk export. Scripted MCP
insertion/export is authoring evidence, not a desktop flow a parent or child
has independently followed. The save lesson's host-export paragraph cannot
substitute for that setup work. Do not publish this pair as a self-contained
first-session pack until the selected host route supplies those exact steps.

The disk-change fix is source revision `6ff929f366e8762d5d5b9dadf53367b2cc692821`,
not every build labelled 0.34.2. It awaits merge/release. The current Save As
workflow must name the available fixed build before public use.

The end goal can be demonstrated with the checked
[styled game capture](https://github.com/emu198x/docs/blob/a35897e2b965b6ec20063d4e2749bce1d412b1cf/plans/2026-10-19-amiga-native-save-investigation/fix/captures/cold-runtime-title.png).
That finished presentation is an example of where the course goes, not code
supplied before its ideas are taught. First-message colours remain those of
the checked AMOS runtime; deliberate palette choices enter at the drawing step.

Before publishing, review the rendered pages and exact editing instructions,
then try the route with an uncoached beginner. We have no learner-trial result.
Do not infer understanding from an emulator accepting the listing.
