## Central idea

**Position, heading and velocity answer different questions.** Position says where the ship is. Heading says which direction its nose points and where the next burn adds velocity. Velocity says how position changes on each update. Turning changes heading, not existing velocity. Releasing thrust removes acceleration, not velocity. Braking is thrust opposing motion; it is not a special command or automatic drag.

Begin a new program. Show the first short listing in full without a redundant list of every line to add. Recall pixel coordinates, signed offsets, variables, arrays, loops and subroutines locally. Later source changes have exact additions, replacements and deletions. No reader imports a previous game's engine.

## Teaching constraints

The heading checkpoint introduces several arrays together because they represent the same eight orientations. Draw the forward/perpendicular construction and trace one axis-aligned and one diagonal entry before showing the whole setup loop. Do not present the arrays as unexplained sprite data or ask the learner to memorise trigonometry. A reader can inspect each table entry and its visible triangle.

The flight checkpoint already permits braking. Lesson four makes that consequence explicit rather than pretending to add it later. Likewise, the readout is not an engine upgrade: it exposes state that already exists. Its cost in interpreted BASIC is part of the observed implementation. Neither INKEY$ polling nor a counted number of updates is a clock; short taps may be missed, and intermediate listings may run faster than the endpoint.

DOCK OK describes speed only. The readout's displayed number is rounded; docking compares the unrounded squared velocity. The threshold is a game-design choice, not a claim about a real spacecraft. Collision uses geometry and never reads screen colour. The rectangular limits conservatively bound the triangle at all eight headings.

Graphics are original BASIC vector artwork. Keep the accepted colours, silence and controls. No extra hazards, fuel budget, levels, automatic drag, brake key or assembly port is introduced.
