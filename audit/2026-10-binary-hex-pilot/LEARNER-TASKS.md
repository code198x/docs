# Binary and hex: learner tasks

Use Counting in Twos units 1–2. Work on paper or in a text document. Predict
before opening the page's answer. You do not need assembly experience.

1. **Read a pattern.** Write the eight place values for `01011010`. Add only
   the places containing a 1. Group it into hex digits and check that the
   decimal, binary and hex readings agree.
2. **Work backwards.** Write decimal 93 as eight binary digits. Show which
   place values you chose and check their sum. Convert the pattern to two hex
   digits without changing its value.
3. **Diagnose grouping.** A short binary number is `11011`. Someone groups
   from the left as `1101 1000` and calls it hex D8. Find the mistake, give
   the correct value and hex form, and explain where padding zeros may go.
4. **Predict a boundary.** Count one beyond hex 0F, then one beyond hex FF.
   Give the full results in hex and decimal. Which can fit an unsigned byte?
   Has writing a leading zero made an out-of-range value fit?
5. **Explain the reading.** Compare `BIN 101`, `BIN 00000101`, `HEX 05` and
   decimal 5. How many different numeric values are present? Which statements
   tell you a real program's storage size? What extra information would you need?
   Does a drawing of on/off switches tell you how every circuit carries current?
6. **Change a pattern.** Start with hex A5. Change only its low nibble to A.
   Give the new hex, binary and decimal forms. Explain which four bits remain
   unchanged and how the value changed.
7. **Make and check a pair.** Choose a value from 128 through 254. Write it in
   decimal, eight-bit binary and two-digit hex. Change one bit and predict the
   numeric difference before recalculating. Write down an independent check
   someone else could use to find a reversed bit order or wrong nibble.

Optional connections:

- In A byte becomes pixels, find the binary marker and explain which pixels a
  pattern selects. Reading its local explanation is enough; record running or
  changing the machine program separately if you do it.
- In Two bytes together, explain the difference between the top unsigned value
  and the number of possible values. Find why an address range is not a claim
  about installed memory.

Record hints before using them. Note which explanation remained unclear; do not
include a child's name or personal details in shared observations.
