# Counts, shares and chance: independent tasks

Use [Compare shares](https://code198x.com/craft/maths-for-games/unit-03/).
You may read the lesson and use paper or a calculator. For the program task, use
a stock 48K Spectrum with the complete maintained shares program. Record any help,
including keyword entry help. You do not need to complete Foundations first.

Try a prediction before revealing a worked answer or running a changed program.
Explain what changed your mind. A working screen and an explanation are separate
observations. The separate assessor sheet contains expected reasoning.

1. **Predict a new table.** A seven-roll sample has face counts 1, 1, 1, 1, 1, 2.
   Find each exact percentage, then each percentage rounded to one decimal place.
   Add the displayed values. Would you change a count if that sum differs from 100?
   Explain what the two totals measure. This is a paper sample, not the unchanged
   unit 3 program's twelve-roll output.
2. **Change the denominator.** In that sample, face six has appeared twice. The
   next roll is a two. Predict face six's new count and displayed percentage before
   calculating. Explain how its share can change without another six.
3. **State the model.** Assume an ideal die with independent rolls and a one-sixth
   chance for each face. Five sixes have just appeared. Is a one now more likely
   than a six? Explain which assumption supports your answer. Could this short
   history alone establish that a real die or a computer generator follows that model?
4. **Diagnose a proposed repair.** Someone changes one displayed percentage so
   the first table adds to exactly 100, then changes its stored tally to match.
   What evidence would you inspect before accepting that change? Describe a repair
   that keeps the recorded events intact. Separately, what would happen if a
   percentage routine used a total of zero?
5. **Modify and check.** Predict how to change the shares program to display two
   decimal places instead of one. State which line to edit. Run the changed program,
   compare all six screen counts and percentages with the total, and explain any
   rounded sum difference. Keep the tally update unchanged. Save the changed listing
   or write down the exact edit. If you cannot enter it, keep your prediction and
   record the help needed rather than treating an answer copied from the assessor
   as an independent modification.
6. **Create a small investigation.** Choose a question about sample size or repeat
   runs that the experiment could explore. Write what you will record, one accounting
   check that must hold, and one conclusion the results could not establish. Explain
   how you would distinguish a counting error from an uneven sample. You may design
   this on paper; extending the program is optional.

For each task, record the prediction, action, actual result, explanation, help and
any revision separately. Stop if you are stuck; the point is to find where an
explanation or control needs work. We have no completed learner observations yet.
