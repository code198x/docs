# CRASH! Live release checks

Release testing for the CRASH! Live launch (17 October 2026), run on 5 October 2026. Spectrum is the launch route; C64, Amiga and NES are a bonus. This report records what was checked, what was fixed and what remains. It complements the [release readiness checklist](../../launch-readiness.md) and the [Spectrum learner journey review](../2026-10-spectrum-learner-journey/REPORT.md).

The Meteor checkpoints and two endpoint options first failed on a 60-second emulator timeout while the machine's load average was about 500 from other sessions. They passed when rerun at normal load. WebKit failures during the same period were timeouts for the same reason, apart from the iPhone experiment-button jump fixed in website #629.

After the six BASIC polish units were merged on top: 241 BASIC units lint and build, the Spectrum audit covers 292 units and 531 listings, `check:release` passes, and the four-browser suite passes. One iPhone test timed out under load and then passed 20 times out of 20 on a quiet machine.

The owner listened to the beeper demo and Meteor Storm's sounds, and has validated the site in Safari and on an iPhone throughout.

## Outstanding

- **Learner trial:** no uncoached learner trial. The owner reports people have looked at the site.
- **First notarised release:** check a browser-downloaded macOS build with `spctl`, then remove the macOS notes from the Spectrum setup pages.
- **Icons:** not yet seen on Windows (`.exe` in Explorer) or Linux. The Dock icon may not cover Cmd-Tab, which would need an `unsafe` call. The macOS Finder icon needs a `.app` bundle.
- **Browser player:** in the lesson panel, Start boots to the copyright screen, and a lesson's tape loads only after Run this lesson. Older lessons behave the same.
- **BASIC games:** the larger polish gaps remain separate scope: sound, progression, best results, drawn titles and loading screens. Sonar's module thumbnail still shows the game before lesson 10.
