# Learner tasks: progress and exits

Use the Repeating overview and units 2–3. Work on paper with the teaching
notation and keep assessor notes separate. A helper should record observations
without coaching. Earlier modules are optional support.

1. Predict the guessing loop after answers 4 and 4. Can it still finish later?
   Does that mean it is guaranteed to finish? Distinguish waiting at ASK from
   repeatedly executing work that never approaches its exit.
2. Trace the lives loop from 3 through its final false test. Record each test,
   displayed value and value after subtraction. Explain why it finishes under
   the stated whole-number and update rules, provided each pass completes.
3. Start with zero lives. Compare a pre-test loop with a post-test version using
   the same show/subtract body and UNTIL lives <= 0. How many passes occur, and
   which version follows the no-lives, no-turn rule?
4. Move LET lives = 3 inside WHILE. Trace the first two passes and the next test.
   Does having a subtraction in the body establish progress? Explain which
   state repeats and the assumptions behind predicting further repetition.
5. Repair that reset placement. Then create a missing-subtraction variant and
   choose an observation that separates it from the inner-reset variant.
6. An audit stops a faulty loop after four passes. Did the original condition
   make the loop finish? State which observations are about the original loop
   and which depend on the audit intervention.
7. Create a small repeated task with a starting value, test, update and intended
   exit. Check zero and small positive starts. Explain whether completion follows
   from progress, depends on outside input, or is not required by its purpose.

Optional: follow the existing random-secret lesson and the saved-flag connection.
Explain why a random choice can repeat, and why a saved condition may need a
fresh assignment. Do not run a suspected unbounded loop without a stop method.

Record the learner's own answers, revisions and requested hints. Leave unaided
completion, timing, retention and transfer unknown until observed.
