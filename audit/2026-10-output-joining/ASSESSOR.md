# Observe output reasoning

Use the [learner tasks](LEARNER-TASKS.md) after the proposed Basics unit 3.
No learner has completed this trial. These are prepared observations, not results.

Record starting experience, independent entry, first prediction, explanation,
repair, assistance and any revision after reading. Keep confident correct answers
separate from guesses and answers reached after hints. Ask “What made you think
that?” without naming the expected separator or missing space.

| Task | Expected reasoning | Watch for |
| --- | --- | --- |
| Quoted sum | `6 + 2` is text; unquoted sum displays `8`; quotes do not print | Treating every plus sign as arithmetic, or printing quote marks |
| Space repair | Original displays `Lives:3`; `SHOW "Lives: ", 1 + 2` displays the intended text | Changing the arithmetic, or expecting the joining comma to supply a space |
| Two text pieces | `Go now` versus `Gonow`; source whitespace outside quotes does not insert output | Assuming the comma is visible or inserts a gap |
| Optional BASIC transfer | Semicolon joins immediately; comma selects a print zone | Copying SHOW punctuation unchanged, or claiming all BASIC dialects share it |

Do not require the term “print zone” before the optional reading. A learner can
explain the correct distinction in ordinary words. If they try actual BASIC,
record the machine, source, result and any help operating it separately from
reasoning about the notation.

For each objective, record independent / after explanation / after coaching /
not yet demonstrated. This is a small qualitative trial, not a validated score
or a pass gate. A correct displayed result alone does not show why it
appeared. A later fresh example can probe retention; label it separately and
record the elapsed time. Do not infer durable learning from one session.

File a bounded issue when an observed obstacle can be described and reproduced.
Include the task, actual response, expectation, assistance and evidence. Avoid
filing the same issue for every learner; search existing open and closed findings.
