Fifty-five published pattern entries are labelled illustrative. The proposed first tranche improves existing loop entries and composes maintained input/sound with movement/contact and clean state transitions; BBC Micro is the first proposed wider-system qualification slice, coordinated with docs #3.

The source validator checks 809 explicit include references and 26 pinned source permalinks, exact pattern/unit enumeration, matrix uniqueness, CSV/JSON agreement and wider-system sources. Its deliberately missing-source control is rejected. No machine execution, curriculum authoring, schema change or deployment was performed for this inventory.
